# 📋 Attendance Management System

## 🚀 Overview

The Attendance Management System is a desktop-based application designed to automate student attendance using **QR code technology**. It eliminates manual entry and ensures accurate, real-time tracking.

---

## 🎯 Features

* 📷 QR Code-based attendance marking
* 🖥️ User-friendly GUI using Java Swing
* 🗄️ Real-time database storage with MySQL
* ⚡ Fast and efficient attendance processing
* 📊 Easy record management and retrieval

---

## 🧠 How It Works

1. Each student is assigned a unique QR code
2. QR code is scanned using the system
3. Attendance is recorded automatically
4. Data is stored in MySQL database

---

## 🛠️ Tech Stack

* **Language:** Java
* **Frontend:** Java Swing
* **Database:** MySQL
* **Connectivity:** JDBC

* Import SQL file from `/database`
